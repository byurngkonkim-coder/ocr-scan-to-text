## 3. 사용자 결정 (재논의 금지)

1. 비용 우선 = OCR 은 RapidOCR 한글 v5, 문장 정제는 **내장 정제규칙**. exaone3.5 는 보류.
2. 정확도 우선으로 읽은 스캔도 정제는 내장 규칙만.
3. ④ 일괄 처리는 비용 우선 강제. 정확도 우선은 ① 단건만.
4. 검토 필요 쪽은 「그 쪽만 다시 읽기」로 처리.
5. 폴백 기준 신뢰도 85 유지 — B2B영업전략 301쪽 실측에서 70~90 결과 동일, 실제 오인식 1쪽(p.242)만 포착 ⟦E2✓⟧.
6. 이미지 품질 진단만으로는 Vision 에 보내지 않는다 — 진단 35쪽 중 34쪽을 RapidOCR 이 원문과 99~100% 일치하게 읽음 ⟦E2✓⟧.

## 5. PC 별 주의

- **결제**: AI Studio 선불 크레딧 유지·자동 충전 끔(사용자가 직접 확인). 충전 뒤 START_OCR 재시작해야 결제 차단이 풀린다.
- **config.json**: `batch_input_dir` 는 PC 전용 절대경로라 커밋하지 않았다(회사 PC 에만 `E:\03DBR pdf_경영경제 읽을거리`). 노트북은 ④ 탭 「폴더 선택…」으로 지정.
- **Ollama**: 정제 기본값이 내장 규칙이라 필요 없음. `local_cleanup_engine: "ollama"` 로 바꿀 때만 exaone3.5 필요(3,000자에 173초 실측 ⟦E2✓⟧).
- 회사 PC 의 `START_OCR.bat` 은 내용 변경 없이 수정 표시만 있어 커밋하지 않았다.
