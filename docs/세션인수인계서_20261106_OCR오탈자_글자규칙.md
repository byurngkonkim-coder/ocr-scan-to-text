## 3. 교정 내역 보기 (백업 원본 ↔ 현재 결과)

자동 교정은 한 글자를 한 글자로 바꾸므로 원본과 결과의 길이가 같다 → 같은 자리끼리 비교하면 바뀐 곳이 나온다(확인 범위: 8권 중 8권, 길이 같음 assert 통과).

실행 결과(2026-11-06, 합계 703곳 — §1 수치와 일치):

| 짝 | 올→을 | 히→하 | 디→다 | 율→을 | 온→은 | 듈→들 | 옴→음 | 률→를 | EG |
|---|---|---|---|---|---|---|---|---|---|
| 곳 | 414 | 164 | 60 | 22 | 16 | 12 | 8 | 7 | E2 |

| 백업 폴더 | 들어 있는 책 |
|---|---|
| `_백업/조사교정_20261106_130640/` | 베스트셀러명언800 · 실리콘밸리천재들의생각아포리즘 · 시네마명언1000 |
| `_백업/조사교정_20261106_134906/` | 손자병법 1·2 · 전략실행 방법론 · 전쟁론 · 전략론 |

스크립트(세션 scratchpad 에 저장해 실행 — 프로젝트에 넣지 않는다):

```python
# diff_fixes.py — 실행: python -X utf8 diff_fixes.py  (프로젝트 루트에서)
import collections, glob, os
pairs = collections.Counter(); rows = []
for bak in glob.glob('_백업/조사교정_20261106_*/*.md'):
    cur = os.path.join('02_결과', os.path.basename(bak))
    a = open(bak, encoding='utf-8').read(); b = open(cur, encoding='utf-8').read()
    assert len(a) == len(b), cur
    for i, (x, y) in enumerate(zip(a, b)):
        if x != y:
            pairs[(x, y)] += 1
            rows.append((os.path.basename(cur)[:30], x, y, a[max(0, i - 12):i + 12].replace('\n', '⏎')))
print(pairs.most_common())
with open('diff_fixes.tsv', 'w', encoding='utf-8') as f:
    f.writelines('\t'.join(r) + '\n' for r in rows)
```

활용: 짝별 건수와 문맥으로 ① 잘못 고친 곳 찾기 ② 두 글자가 같이 깨져 고쳐도 틀린 곳(`히께→하께`, `타협히국→타협하국`) 모으기 → 새 유형(§4-D) 근거.
