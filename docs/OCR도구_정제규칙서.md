# 🧹 OCR 정제(교정) 규칙서

> **이 문서의 기본 증거등급: E2** — 규칙은 `04_처리엔진/core/text_cleaner.py` 구현과 `tests/test_text_cleaner.py` 로 재현·확인한다.

> [!NOTE]
> **핵심 3줄 요약**
> 1. OCR이 **충실 추출**한 원문의 '레이아웃 오염'(쪽번호·러닝헤더·`[페이지]`마커·페이지넘김 어절분리·띄어쓰기/맞춤법)을 문서 전체 맥락에서 **Gemini로 교정**해 마커 없는 클린 플레인텍스트로 되돌린다.
> 2. 규칙은 **정제 규칙 `C-01~C-11`** + **청크 분할 규칙 `CK-01~CK-02`** 로 구성. 구현은 `core/text_cleaner.py`.
> 3. **원문 충실 원칙**을 지킨다 — 없는 내용을 지어내지 않고, 부속물(표제지·판권·차례)은 기본 보존(옵션으로만 제거).

## 1. 목적 및 위치

- **목적**: 스캔 서적 OCR 결과를 **학습용/타이핑용 고품질 plain text**로 복원.
- **입력**: `gemini_vision.run()`이 페이지별로 충실 추출한 텍스트(페이지 리스트).
- **출력**: `[페이지 N]`·구분선 없는 순수 본문(단락 = 빈 줄). `writer.write_plain()`으로 저장.
- **엔진**: 현재 **Google Gemini** 텍스트 호출(`gemini_vision.run_text()`). thinking off·타임아웃·1회 재시도.
- **파이프라인 위치**:
  ```
  OCR(페이지별 충실 추출) → [정제(본 규칙서)] → 클린 플레인텍스트(.txt)
                                  └ core/text_cleaner.py
  ```
- **적용 시점**: 웹 UI **📝 문장 정제** 토글 ON(Vision 모드 기본) + **전체 처리** 시. (미리보기는 속도 위해 제외)

> ⚠ **명언 정제 파이프라인과 구분**: `02_01/04_처리엔진/normalize_pipeline.py`(`N-01~S-07`)는 *명언 모음집을 "명언_저자"로 추출*하는 도구다. 산문 책에 쓰면 문장을 조각내므로 **책 정제에는 본 규칙서(C-xx)를 쓴다.**

## 3. 정제 규칙 (C-01 ~ C-11)

> 규칙 본문은 `text_cleaner.CLEAN_PROMPT`(+옵션 규칙)에 반영돼 LLM이 문서 맥락에서 적용한다.

### C-01 · 페이지 표시·인공 구분선 완전 제거
- `[페이지 N]` 헤더와 OCR 산출 시 삽입된 점선(`─`×60 등)을 **완전 소거**.
- **원리**: 이 마커들은 OCR이 아니라 `writer._build_txt()`가 넣는 것 → 정제본은 `writer.write_plain()`으로 **애초에 넣지 않고**, 잔여분은 규칙으로 제거.
- 검증: 전체본에서 `[페이지` 0개, `──────` 0개.

### C-02 · 반복 목차·머리말/꼬리말(러닝헤더) 제거
- 페이지마다 따라다니는 **쪽번호·챕터명·책 제목**(예: `이 책의 활용법 11`, `12 우울한 날엔 니체`)을 문맥 분석으로 **본문 흐름 손상 없이** 제거.
- **경계**: 책 앞부분의 **정식 차례(목차) 블록**은 본문 콘텐츠로 **보존**(러닝헤더만 제거). 목차까지 빼려면 → **C-10**.

### C-03 · 페이지 경계 잘린 어절 자동 결합
- 페이지가 바뀌며 앞뒤로 찢어진 단어/문장을 **한글 어법에 맞게 하나로 재결합**.
- 예: `…가치가 있으며, 성` 〔페이지경계·꼬리말〕 `찰의 노력 없이는…` → `…가치가 있으며, 성찰의 노력 없이는…`
- **구현 신호**: 페이지 사이에 센티넬 `⟨PAGEBREAK⟩`를 넣고, 프롬프트가 "경계는 삭제하되 잘린 단어는 이어 붙여라"고 지시(`text_cleaner.PAGEBREAK`).

### C-04 · 정밀 띄어쓰기
- 한국어 어법에 맞게 띄어쓰기 적용. 예: `할수있다`→`할 수 있다`, `좀더`→`좀 더`.

### C-05 · 문맥 기반 오타·변환 오류 교정
- 전후 문맥으로 자연스럽게 교정. 예: `님외`→`남의`, `중고는`→`충고는`, `가중쇼한`→`가장 중요한`, `기봄`→`기쁨`, `Groupe Eyrolles SASH`→`SA와`.
- **원문 충실**(C-09): 확실하지 않으면 바꾸지 않는다.

### C-06 · 외래어 영문 병기 괄호쌍 완성
- 불완전한 괄호를 완성. 예: `제물(wealth`→`제물(wealth)`, `컴퓨터 Computer)`→`컴퓨터(Computer)`.
- URL·이메일의 스캔 공백도 복원. 예: `(www.\nbalthasar-thomass. fr)`→`(www.balthasar-thomass.fr)`.

### C-07 · 자모 노이즈·불릿·스캔줄 제거
- 단독 자모(`ㄱ`,`ㄴ`), 스캔 줄(`──`), 특수 기호 불릿을 제거.

### C-08 · 단락 = 빈 줄 포맷
- 단락마다 **빈 줄(`\n\n`)** 로 구분. 설명문·머리말 없이 **정제된 본문만** 출력.

### C-09 · 원문 충실 (지어내기 금지)
- 원문에 **없는 내용을 생성하지 않는다**. 정제는 '복원·교정'이지 '재작성'이 아니다.

### C-10 · (옵션) 앞부속(front matter) 제거 — 기본 OFF
- 켜면 **표제지·판권(저작권)면·차례·헌사·제사(에피그래프)·시리즈 광고**를 제거하고 **본문만** 남긴다.
- **본문이 시작되면 그대로 둔다** — 부속물이 끝나는 지점을 지능적으로 판별.
- 구현: `_RULE_FRONT_MATTER`. 본문이 나올 때까지(`body_started`) **앞 청크에만** 적용 → 중간 본문 미손상.

### C-11 · (옵션) 뒤부속(colophon) 제거 — 기본 OFF (C-10과 동반)
- 책 끝의 **판권지·간기**(출판사·주소·전화·팩스·이메일·ISBN·인쇄정보·CIP)와 광고를 제거.
- 구현: `_RULE_COLOPHON`. **마지막 청크에만** 적용.

## 4. 청크 분할 규칙 (CK-01 ~ CK-02)

> 모델 출력 토큰 한계 때문에 문서를 여러 번에 나눠 정제한다. 이때 **어떤 구간에서도 문장/어절이 청크 경계에서 잘리지 않도록** 한다. 구현: `text_cleaner._chunk_pages()`.

### CK-01 · 페이지 단위 청크 (페이지는 절대 중간에서 쪼개지 않음)
- 청크는 **페이지들의 묶음**이다. 한 페이지를 반으로 자르지 않는다 → 청크 안에서 **페이지 넘김 어절 결합(C-03)** 이 항상 가능 ⟦E2✓: `_chunk_pages` 소스 대조 — 페이지를 통째로만 append, 2026-09-26⟧.
- 목표 크기: `cleanup_chunk_chars`(기본 4000자, soft) / 상한 그 2배(hard).

### CK-02 · 문장 완결 기준 경계 + 문장 끝 스냅
- **soft(≥4000자)**: 누적이 목표를 넘고 **현재 페이지가 문장으로 깔끔히 끝**(`. ! ? … " ) 」 』` 등)나면 그 페이지에서 끊는다.
- **hard(≥8000자)**: 문장이 계속 이어져 soft 지점을 못 잡았으면 강제 분할하되, **마지막으로 문장이 끝난 페이지까지만** 넣고 나머지는 다음 청크로 **이월(carry)** → 경계를 문장 끝으로 **스냅**. 단, 문장이 끝나는 페이지가 하나도 없이 hard를 넘으면 그 페이지에서 그대로 끊는다(이때도 페이지 중간은 자르지 않음) ⟦E2✓: `_chunk_pages` 362~369행 대조, 2026-09-26⟧.
- **판정**: `_page_ends_cleanly(page)` — 페이지의 마지막 의미 있는 줄이 종결 부호로 끝나는가(`_SENT_END` 정규식).

> 결과: 청크 경계는 대부분 문장 끝에 놓여 청크 사이에서 단어가 갈라지지 않는다. 예외는 문장 끝 페이지 없이 8000자를 넘는 경우 하나이며, 이때도 경계는 페이지 사이에만 생긴다 ⟦E2✓: `_chunk_pages` 소스 · `test_hard_break_snaps_to_last_clean_page`, 2026-09-26⟧.

## 5. 실패 안전 (강등) + 청크 무결성 가드 (G-01, 2026-07-06 신설)

- 특정 청크에서 **API 오류** 발생 시 그 청크만 **규칙 기반 최소 정제**(`_fallback_clean`: 센티넬 제거 + `postprocessor.join_broken_lines`)로 강등 → **배치 전체가 죽지 않는다**.
- 모델 출력에 잔여 센티넬/코드펜스가 있으면 `_strip_output()`이 제거.
- **G-01 · 청크 무결성 가드**: Gemini는 안전필터 차단·조기 종료 시 **오류를 던지지 않고 빈/과소 응답**을 돌려준다(`response.text or ""`) ⟦E1: 2026-07-06 메시지성경 신약 842p 실측 사고⟧. 실측 사고 — 메시지성경 신약 842p에서 계시록 14~18장·마태복음 4:1-12 등 여러 청크가 빈 응답 수용으로 **통째 소실**(2026-07-06). 대책: 정상 정제는 레이아웃 노이즈만 걷어내므로 출력 비공백 길이가 입력의 90%+ 라는 성질을 이용해, 출력/입력 비공백 비율이 **0.75 미만이면 응답을 버리고 1회 재시도, 그래도 미달이면 원문 보존 강등**(여백 필터를 켠 경우 0.90, 뒤부속 제거 청크는 0.30, 앞부속 제거 청크는 '전부 삭제→빈 출력'이 정당하므로 미적용) ⟦E2✓: 비율 0.75·0.90·0.30은 `text_cleaner._output_ok` 대조, 2026-09-26⟧. 발동 내역은 `get_last_report()`로 UI 로그에 표시.
- **원문 안전망**: 정제본을 저장할 때 정제 전 원문(페이지 마커 포함)도 `04_처리엔진/storage/results/{ts}_{이름}_원문.txt` 로 함께 보존 — 정제 단계 사고가 나도 원문으로 복구 가능. 원문 작성이나 보관소 저장이 실패하면 사본은 남지 않지만, 진행 기록과 완료 요약에 **"정제 전 원문 사본을 … 못했습니다(복구용 원문 없음)" 경고**가 뜬다 ⟦E2✓: `tests/test_raw_copy_warning.py` 디지털·OCR 두 경로 6건 통과, 2026-09-26⟧.
- **본문 고유 번호 보존**: 프롬프트 규칙 3에 "성경 장·절 번호·법조문 번호·목록 번호는 콘텐츠이므로 보존" 명시 — 러닝헤더 제거 규칙이 절 번호까지 지우던 과제거(히브리서 2~7장 실측) 방지.

## 6. 정규 프롬프트 (canonical)

> 아래는 `text_cleaner.CLEAN_PROMPT`의 규칙부. `{TEXT}` 자리에 `⟨PAGEBREAK⟩`로 이어붙인 페이지들이 삽입된다. C-10/C-11 옵션이 켜지면 규칙 7·8이 뒤에 덧붙는다.

```
[수행 규칙]
0. 무손실 원칙(최우선): 모든 본문 문장을 빠뜨리지 말고 순서 그대로 전부 출력.
   요약·축약·생략·재배열 금지. 반복적·단조로운 구간(족보·목록)도 전부 출력.
   불확실한 교정은 원문 유지. 3번 열거 항목 외 삭제 금지.
1. 문맥 파악 및 단어 복원: 전후 문맥으로 오타·변환 오류를 자연스럽게 교정. (님외→남의)
2. 정밀 띄어쓰기 및 맞춤법: 한국어 어법에 맞게 적용. (할수있다→할 수 있다)
3. 레이아웃 노이즈'만' 제거(열거 한정): ①쪽번호(단독 숫자) ②러닝헤더/푸터 —
   페이지 맨 위/아래(입력 맨 앞뒤·⟨PAGEBREAK⟩ 앞뒤)의 '책 제목' 단독 줄이나
   '마태복음 5'형 제목+쪽수 짧은 줄 ③자모 노이즈 ④스캔 줄('──') ⑤기호 불릿.
   단, 본문 고유 번호(성경 장·절·법조문·목록 번호)는 콘텐츠이므로 반드시 보존.
   ('장/절 헤더 삭제' 구표현은 성경 절 번호 오삭제를 유발해 폐기 — 2026-07-07)
4. 페이지 경계 처리: '⟨PAGEBREAK⟩'는 삭제. 경계에서 잘린 단어/문장은 이어 붙임. (성⟨PAGEBREAK⟩찰의→성찰의)
5. 외래어 영문 병기 완성: 불완전 괄호쌍 완성. (제물(wealth→제물(wealth))
6. 출력 포맷: 단락마다 빈 줄. 정제 본문만 출력, 설명 배제, 없는 내용 생성 금지.
--- (옵션 C-10/C-11) ---
7. 앞부속 삭제: 표제지·판권·차례·헌사·제사·시리즈 광고 제거, 본문 시작 후는 보존.
8. 뒤부속 삭제: 판권/간기(출판사·주소·전화·ISBN·인쇄·CIP)·광고 제거.
```

## 7. 설정 (`config.json`)

| 키 | 의미 | 기본값 | 게터 |
|---|---|---|---|

## 9. 하지 않는 것 (경계)

- **원문 재작성·요약 금지**(C-09). 정제는 복원·교정까지.
- **부속물 기본 보존**: 표제지·판권·차례는 옵션(C-10/C-11)을 켜야만 제거.
- **명언 추출 아님**: `normalize_pipeline.py`(N/S 규칙)의 역할과 분리.
- **VISION_PROMPT은 그대로 '충실 추출' 유지**: 정제기가 전체 맥락을 보고 판단하도록 OCR 단계에서 정보를 미리 버리지 않는다.
