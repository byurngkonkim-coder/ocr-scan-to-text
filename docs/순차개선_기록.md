# 결과 파일 순차 개선 기록

> 기본 증거등급: **E2**(재처리 도구 실행 결과로 확인 — 재현 명령은 각 회차 「재현」 칸)

`02_결과` 의 결과를 오래된 것부터 한 권씩 다시 만들어 오류 원인을 찾고, 일반화되는 것만 규칙·테스트로 만든다.
다음 권은 지금까지 쌓은 규칙을 그대로 적용한 결과에서 새 오류를 찾는다.

## 진행 방법

1. **책 정보 모으기** — 인터넷 검색(교보·예스24·알라딘)과 원본 스캔 PDF 앞쪽(`C:\Users\bkkim\Documents\역량강화\스캔서적\`)에서 책·저자·차례를 확인해
   `02_결과/_재처리/_책정보/{결과 이름}.txt` 에 적는다(형식은 `engine/tools/reprocess_book.py` 머리 설명).
2. **다시 만들기** — `engine/venv/Scripts/python.exe engine/tools/reprocess_book.py {결과 이름}` →
   `02_결과/_재처리/{결과 이름}.md`(원래 결과는 그대로).
3. **대조** — 원래 결과와 비교: 장·절 제목 수, 본문 한글 글자 수(줄면 이유 확인), 지적 항목 수.
4. **규칙화** — 여러 책에 생길 오류만 규칙+테스트로. 그 책에만 있는 오타는 `engine/user_typos.tsv`.
5. **회귀** — 전체 테스트(`python -m pytest engine/tests`) + 앞 회차 책들을 다시 돌려 나빠지지 않았는지.

## 누적 규칙 (다음 권에 그대로 적용됨)

| # | 규칙 | 위치 | 처음 발견 |
|---|---|---|---|
| 1 | 쪽 가장자리 영문 장식·그림을 피해 짧게 꺾인 줄이 낱말을 가르면 잇고, 장식은 문단 뒤로 옮김 | `postprocessor._split_word_join` | 보라빛소가온다 |
| 2 | 한 글자씩 띄운 쪽 머리글(책에서 3번 이상, OCR 변형 포함)을 본문에서 지움 | `text_cleaner.strip_spaced_running_header` | 삶의지혜_자아편 |
| 3 | 장 번호 표지('03') 둘레에 흩어진 장 제목을 차례 제목 줄로 세움, 번호를 못 읽었으면 앞뒤 장 사이에서 제목 글자로 찾음 | `text_cleaner.place_split_titles` | 삶의지혜_자아편 |
| 4 | 본문 앞쪽에 남은 OCR 차례 덩어리 지움(맨 앞 차례 목록과 중복) | `text_cleaner.drop_toc_remnant` | 삶의지혜_자아편 |

| 6 | 책정보 파일 차례를 쓸 때는 제목을 OCR 줄 글자로 바꾸지 않음 | `rematch_headings(keep_titles=)` | 삶의지혜_자아편 |
| 7 | 책정보 파일 차례를 쓸 때 옛 결과의 OCR 제목 줄('# 감사의삶')을 보통 줄로 되돌려 다시 맞춤 | `remake_md.rebuild` | 1001가지기독교명언 |

| 10 | 번호 항목 책에서 따로 선 번호 문단('77')을 다음 항목 앞에 붙임(번호가 늘어나는 사슬 20개 이상일 때만) | `text_cleaner.attach_item_numbers` | 1001가지기독교명언 |
| 11 | 책마다 다른 고침은 책정보 파일 `바꾸기: 정규식 => 바꿀 글` 줄로(일반 규칙으로 만들지 않음) | `tools/reprocess_book.py` | 1001가지기독교명언 |
