## 1. 배경 및 문제
- 현재 문제: OCR 결과물에 **글자를 잘못 읽은 오타**와 **띄어쓰기 오류**가 남는다(사용자 답변).
- 외부 검사기 검토 결과(채택 안 함 — 사용자 결정 "API 방식이 아닌 로컬"):
  - py-hanspell(ssut): 네이버 인증 키 변경으로 동작 안 함(`KeyError: 'result'`). `pip install git+…` 도 같은 코드라 마찬가지.
  - 9beach/hanspell(네이버·다음): 동작함(시험 5곳 중 네이버 5, 다음 4). 그러나 비공식 호출·본문 외부 전송.
- 로컬 후보 실측:
  - Kiwi 오타 모드: 결과 1권(『지혜의 기술』, 문장 2,007개)에서 42곳을 바꿨고, 맞게 고친 곳은 약 10곳·틀리게 바꾼 곳은 약 28곳 ⟦E3: 눈으로 판정한 추정⟧. → 자동 교정 불가, **후보 추출용**으로만 쓴다.
  - Ollama: GPU 없는 PC 라 CPU 추론뿐 → 책 단위로는 너무 느림. 제외.
- 이미 있는 것: 새로 처리하는 결과에는 오타 사전(`korean_corrector.TYPO_DICT`)과 R-17 띄어쓰기(`core/spacing.py`, 넣기만·5자↑ 덩어리만)가 이미 적용된다. 하지만 R-17 이전(2026-10-17 오전 이전)에 만든 `02_결과` 파일에는 적용되지 않았다(예: 「발타자르그라시안지음차재호옮김」이 그대로 남아 있음).
- 영향받는 업무/사용자: ④ 일괄 처리로 책을 텍스트로 바꾸는 사용자(PM 본인). 결과 txt 를 위키·책 스킬 원본으로 쓴다.

## 2. 목표
- 달성하려는 결과:
  1. **자동 교정** = 오타 사전 + 안전한 범위의 Kiwi 띄어쓰기(R-17 그대로).
  2. **의심 목록** = Kiwi 오타 모드가 고치자고 하는 곳을 본문은 바꾸지 않고 목록으로만 보여 준다.
  3. **사전 등록** = 사용자가 목록에서 확인한 것만(고칠 말을 직접 바꿀 수 있음) 사전에 넣고, 다음 처리부터 자동 교정한다.
  4. 이미 만든 `02_결과` 파일에도 1·2를 다시 적용한다(덮어쓰기, 백업 1회).
- 성공 기준:
  1. 글자 교정 오교정 0건 — 글자를 바꾸는 것은 사람이 등록한 사전 항목뿐이다.
  2. 띄어쓰기는 R-17 기존 측정치(넣은 것 정확도 89.6%)를 유지하고 범위를 넓히지 않는다.
  3. 의심 목록은 본문을 바꾸지 않는다(재교정 전후 글자 비교로 확인).
  4. 등록한 항목이 다음 처리·재교정에 실제로 반영된다(회귀 테스트).
  5. `python -m pytest engine/tests` 실패 0건.

## 3. 범위
### 포함
- ④ 일괄 처리: 결과와 함께 의심 목록 저장
- ④ 탭에 「결과 파일 다시 교정」: `02_결과` txt 선택 → 백업 → 자동 교정 → 덮어쓰기 → 의심 목록
- ④ 탭에 의심 목록 표: 등록 체크 · 틀린 말 · 고칠 말(수정 가능) · 문맥 · 횟수 → 「선택 항목 사전 등록」
- 사용자 사전 파일(01_OCR 전용) 읽기·쓰기와 정제 단계 적용
### 제외
- 외부 검사기(네이버·다음·py-hanspell) 호출
- Hunspell(spylls) — 사용자 결정으로 제외
- Kiwi 오타 모드 제안을 확인 없이 본문에 적용하는 것
- R-17 띄어쓰기 범위 확장(넣기만·5자↑ 규칙 유지)
- ① 처리하기 화면 변경
- 쓰이지 않는 py-hanspell 연동 코드(`engine/core/spellcheck.py` L2) 정리 — 동작에 영향이 없어 그대로 둔다

## 6. 주요 프로세스
1. 일괄 처리: OCR → 오타 사전(기본+사용자) → 정제 → R-17 띄어쓰기 → 결과 저장 → 의심 목록 저장
2. 기존 결과: ④ 탭에서 결과 파일 선택 → `_백업/` 보관 → 1번의 교정 단계만 적용 → 덮어쓰기 → 의심 목록
3. 사전 키우기: 의심 목록 표에서 맞는 것을 체크(고칠 말 수정 가능) → 등록 → 이후 처리·재교정에 자동 반영

## 7. 예외 및 리스크
| 상황 | 처리 방향 |
|---|---|
| Kiwi 제안이 틀림(예: 흘륨→흙륨, 정답 훌륭) | 본문 미적용. 사용자가 고칠 말을 고쳐서 등록 |
| 등록한 짧은 낱말이 다른 낱말 속에서 바뀜 | 등록 시 2자 미만 거부 + 등록 전 「본문에서 몇 곳 바뀌는지」 표시 |
| 같은 결과를 두 번 재교정 | 사전·R-17 모두 두 번 적용해도 결과가 같아야 함(테스트로 확인) |
| 백업 폴더에 같은 이름이 이미 있음 | 시각을 붙여 따로 보관, 기존 백업 덮어쓰지 않음 |
| Kiwi 오타 모드가 느림 | 1권 처리 시간을 측정해 보고. 너무 느리면 의심 목록을 끌 수 있게 |
| 의심 목록이 너무 많음(1권 수십~수백 곳) | 같은 틀린 말을 묶고 횟수순 정렬 |
