# Intent: NotebookLM 질의응답·요약·인용 검증용 MD 구조 개선

> 기본 증거등급 E2(02_결과·storage 파일 측정). 재현 명령은 §10.

## 1. 배경 및 문제
- 목적: 대용량 책 스캔본 OCR 결과를 NotebookLM 에 넣어 **요약·질의응답 시 누락 없이**, 답변의 **근거(인용)를 원본 책과 대조**할 수 있게 하는 것.
- 현재 MD 생성 구조(정제 켠 경로): `text_cleaner.iter_clean` → `toc_headings`(차례 읽기·본문 제목 표시) → `ocr_gradio._structured_texts` → `toc_headings.to_markdown`(맨 앞 `# 차례` 목록 + 본문). 정제를 끈 경로는 `writer._build_md`(`## 페이지 N`).
- 현재 문제(02_결과 MD 48개 측정, 2026-10-24):
  | 문제 | 측정 | 예 |
  |---|---|---|
  | 차례 인식 실패 → 장 구분 없는 한 덩어리 | 48개 중 10개 차례 없음, 그중 6개는 제목 0개 | `Management by Map` 34만 자·`1Q84` 229만 자 제목 0 |
  | 차례는 찾았으나 본문 제목 연결 부족 | 차례 항목 대비 본문 제목 | `2x2Matrix` 72→10, `NLP행복코드` 10→1, `NextSociety` 49→25 |
  | 차례 단계 오류 | 번호표와 제목이 다른 단계로 갈라짐, 제목 띄어쓰기 소실 | `- 제1장` / `- 다음사회의모습`, `제1부미리가본다음사회` |
  | 쪽번호 정보 없음 | 정제본 MD 38개 전부 쪽 표지 0 | NotebookLM 인용 문단이 책 몇 쪽인지 대조 불가 |
  | 문서 정보 없음 | 책 제목·저자·출처가 MD 에 없음 | NotebookLM 이 여러 책을 섞어 넣으면 출처 구분 약함 |
  | 첫 제목 앞 잡문 | 첫 제목 앞 글자 수 최대 18만 자 | `2천년의강의` 179,741자, 표지·광고 문장 잔존 |
- 영향받는 사용자: 스캔 경영서를 OCR → NotebookLM 에 올려 요약·질의하는 사용자 본인.

## 2. 목표
- 달성하려는 결과: 한 권의 MD 가 **문서 정보 → 차례 → 장·절 단위 본문(제목 계층) → 쪽 경계 표지** 구조를 갖고, 원문 글자는 빠짐없이 들어간다.
- 성공 기준(확인 가능한 형태):
  1. **무손실**: 새 MD 에서 표지(제목·쪽 표지·문서 정보)를 뺀 본문 글자 수가 같은 입력의 현재 정제본 본문 글자 수의 99% 이상(차례 쪽 항목 이동분 제외)
  2. **쪽 표지**: 원문 쪽이 바뀌는 자리마다 `[p.N]` 한 줄. 표지 수 = 내용 있는 쪽 수(빈 쪽·제거된 표지/광고 쪽 제외)와 일치
  3. **장 구조**: 차례를 찾은 책은 차례 항목 대비 본문 제목 연결률을 현재보다 올린다 — 기준 표본(`2x2Matrix`·`NextSociety`·`NLP행복코드`·`MBA명강의`·`First,BreakAllTheRules`)에서 80% 이상
  4. **차례 단계**: `제1장` + 다음 줄 제목처럼 번호표만 따로 읽힌 항목은 한 항목(`제1장 다음 사회의 모습`)으로 합쳐 같은 단계에 둔다
  5. **차례 없는 책**: 본문 제목 꼴(제N장·Chapter N·장 표제지)로 장을 추정해 제목을 단다. 그래도 못 찾으면 쪽 표지만 남기고 통째 유지(지금보다 나빠지지 않음)
  6. **문서 정보**: MD 맨 앞에 책 제목·저자(파일명에서)·원본 파일명·쪽 수·처리일·차례 연결 결과를 짧게
  7. **기존 결과 재변환**: OCR·API 호출 없이 저장된 정제 전 원문 사본(`engine/storage/uploads/*_원문.*`)으로 새 구조 MD 를 다시 만들 수 있다
  8. `python -m pytest engine/tests` 실패 0건 + 새 동작 테스트 추가

## 3. 범위
### 포함
- 정제 켠 경로의 MD 구조: 문서 정보 머리말, 차례, 제목 계층, 쪽 경계 표지 `[p.N]`
- 차례 인식 보강: 번호표 단독 줄 합치기, 제목 띄어쓰기 보존, 본문 제목 연결률 개선
- 차례 없는 책의 장 추정(규칙 기반, 로컬)
- 기존 02_결과 재변환 기능(저장된 원문 사본 → 새 MD, OCR·API 0회)
- txt+md 짝 저장 시 `.txt` 에도 같은 쪽 표지(`[p.N]`)를 넣을지는 §8-3
### 제외
- AI 생성 내용(장별 요약·핵심어·질문 목록) — 원문 인용으로 오인될 위험(사용자 결정 2026-10-24)
- OCR 인식 정확도 자체 개선(오탈자·잡음 줄 교정은 별도 과제)
- NotebookLM 자동 업로드
- 정제를 끈 경로의 `writer._build_md` 서식 변경(지금처럼 `## 페이지 N`)

## 5. 제약 조건
- 원문 근거만 — 생성·요약 문장 넣지 않음
- 새 외부 패키지 없음, 로컬 처리(일괄은 API 다시 읽기 없음 — 요금 최소화 원칙)
- `toc_headings.py` 를 고치면 MyOCR 사본도 같이 맞춘다(`test_toc_headings.py` 바이트 동일 검사)
- 쪽 표지는 정제(줄 잇기·문단 합치기·띄어쓰기 교정)를 거쳐도 살아남아야 한다 — 지금은 정제가 쪽 경계를 합쳐 쪽 정보가 사라짐

## 6. 주요 프로세스
1. 쪽별 OCR 결과에 쪽 번호를 붙인 채 정제에 넣는다(쪽 경계 표지를 정제 중 보호)
2. 차례를 읽는다 — 번호표 단독 줄 합치기, 제목 원래 띄어쓰기 유지
3. 차례가 있으면 본문 제목 연결(연결률 개선), 없으면 본문 제목 꼴로 장 추정
4. 출력: 문서 정보 → `## 차례` → 장·절 제목 계층 본문, 쪽이 바뀌는 자리마다 `[p.N]`
5. 기존 결과 재변환: 원문 사본 선택 → 2~4 반복(OCR·API 없음) → 02_결과에 새 MD

## 7. 예외 및 리스크
| 상황 | 처리 방향 |
|---|---|
| 쪽 경계가 문장 중간 | 표지를 문장 중간에 끼우지 않고, 그 문장이 끝난 뒤 줄에 `[p.N]` (문장 단위 검색 보호) — §8-1 확인 |
| 원문 사본 없는 기존 결과(48개 중 17개) | 재변환 불가 → 원본 PDF 로컬 재처리 대상 목록으로 보고(§8-4) |
| 장 추정 오탐(본문 속 '1.' 목록을 장으로) | 차례 없는 책에만, 보수적 꼴(제N장·Chapter·장 표제지 쪽)만 사용. 확신 낮으면 제목 안 붙임 |
| NotebookLM 소스 크기 한도 | 한 소스 50만 단어 한도 ⟦E3: 공개 안내 기억 기준 추정, 구현 전 확인⟧ — `1Q84`·`king_james_bible`(약 230만 자)은 넘을 수 있음 → §8-2 |
| toc_headings 변경이 MyOCR 동작을 바꿈 | MyOCR 테스트도 같이 돌려 확인 |

## 8. 미해결 질문 → 결정 (2026-10-24, 사용자)
1. 쪽 표지 위치: 쪽이 문장 중간에서 바뀌면 **그 문장이 끝난 뒤 줄**에 `[p.N]`(문장을 끊지 않는다)
2. NotebookLM 한도를 넘는 큰 책: **부·장 경계에서 파일을 나눠** `_1of3.md` 처럼 저장. 한도 안이면 한 파일. 나눈 파일마다 문서 정보·전체 차례 포함
3. txt+md 짝일 때 `.txt` 에도 `[p.N]` **넣음**(두 파일 본문 동일 유지)
4. 원문 사본 없는 기존 결과 17개: **재처리 대상 목록만 보고**(재처리는 이번 범위 밖)
5. 쪽 번호 기준: `[p.N]` 의 N 은 **PDF 쪽**(스캔 파일에서 바로 찾는 번호)
- 남은 확인: NotebookLM 소스 한도 수치(§7, 구현 전 공식 안내로 확인)

## 11. 구현 계획 (검토 대기)

### 11.1 search-first 결정
| 기능 | 찾은 것 | 결정 |
|---|---|---|
| 쪽 표지 `[p.N]` | 프로젝트: `text_cleaner.PAGEBREAK` 센티넬(정제가 지움 → 쪽 번호 못 실음). 외부: pymupdf4llm(AGPL, 텍스트층 PDF 전용)·docling(MIT, 파이프라인 전체 대체)·marker-pdf(GPL, 모델 필요) — OCR 정제본 후처리 용도 아님 | **직접 만들기**(표준 라이브러리) — 정제 뒤 원문 쪽↔정제본 글자 대조. 시험: 5권 쪽의 96~98% 위치 확인(§10) |
| 문장 끝 뒤 표지 | `text_cleaner._SENT_END` | **그대로 쓰기** |
| 차례 단계·띄어쓰기 | `toc_headings`, `spacing.fix_spacing` | **확장** |
| 차례 없는 책 장 추정 | `toc_headings._LEVEL_PATTERNS`·`CHAPTER_LABEL_RE`, `text_cleaner._is_heading_line` | **조합** |
| 큰 책 나누기 | LangChain 등 텍스트 분할기 — 의존성 과다, 장 경계 기준 아님 | **직접 만들기**(`#` 장 경계에서 단어 수로 자름) |
| 기존 결과 재변환 | `reclean.py`(백업→교체 흐름·② 교정 화면), `storage_manager.raw_copy_path` | **감싸기** |
| MCP·스킬 | notebooklm-mcp(업로드 — 범위 밖), book-pipeline·book-to-skill(후속 활용 — 해당 없음) | 해당 없음 |
